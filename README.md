# DF Translator

Переводчик экрана для китайской версии Delta Force (三角洲行动). Снимает экран, распознаёт текст локально и переводит по лор-глоссарию. **Ничего не внедряется в игру.**

## Установка
1. Скачайте `DFTranslator.exe` из [последнего релиза](../../releases/latest).
2. Запустите. Значок «译» появится в трее, откроется панель управления.
3. Игру переведите в режим «Окно без рамки».

Дальше программа обновляется сама. Первый запуск может занять до минуты — распаковка и загрузка OCR. SmartScreen может предупредить о неподписанном файле: «Подробнее» → «Выполнить в любом случае».

## Горячие клавиши (меняются в панели)
`Ctrl+Alt+T` весь экран · `Ctrl+Alt+R` область · `Ctrl+Alt+C` убрать · `Ctrl+Alt+M` режим · `Ctrl+Alt+Q` выход

Новая версия: поправить код, затем `git tag v1.0.1 && git push origin v1.0.1` — Actions соберёт exe и выложит релиз; у пользователей он подтянется сам. Текст релиза — `RELEASE_NOTES.md` (показывается в программе как «Что нового»).
